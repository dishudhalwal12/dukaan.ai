📖 REST API & n8n Integration Guide

1. Sending WhatsApp Messages from n8n (HTTP Request Node)

In your n8n workflow, add an HTTP Request node to send messages anytime:

Method: POST
URL: http://localhost:3000/api/send
Headers: Content-Type: application/json
Body Parameters (JSON):
{
  "to": "919876543210",
  "message": "Hello from n8n! Your automation completed successfully."
}

2. Incoming Message Payload Received by n8n Webhook

Your n8n Webhook node receives this clean JSON structure on every incoming WhatsApp message:

{
  "event": "message.received",
  "from": "919876543210",
  "name": "Alice Smith",
  "text": "Hey, what's my order status?",
  "timestamp": "2026-10-13T17:15:00.000Z",
  "isGroup": false,
  "fromMe": false
}

3. Quick cURL Test

curl -X POST http://localhost:3000/api/send \
-H "Content-Type: application/json" \
-d '{"to": "919876543210", "message": "Test from terminal"}'
