Support

Send a message and we will reply. For an order that is already with a shop, the shop's phone number is on the order and is usually faster.

The contact details are inside the app: open Settings, then Help Center. If you are reading this inside the app, the same screen has the number to call.

The assistant cannot find a shop

Allow location on the consent page, or send a pincode or a map pin in the chat. A saved position older than 30 days is ignored, so a fresh pin is needed after a move.

An order is waiting

Waiting for the shop to accept means the shop has not looked at it yet. You can cancel until it accepts. After that, call the shop with the number on the order.

A wrong address

Ask the assistant to delete the saved address and add the correct one. An order that is already placed keeps the address it was placed with, so tell the shop if it is on the way.

Remove a saved location or an assistant

The saved position is removed on the consent page. An assistant is revoked from the connected apps in your account, which stops it from reading shops or placing orders immediately.

Privacy

What is stored, and how to delete it, is on the privacy page.
